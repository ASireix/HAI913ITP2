# Micro jeu fourni

Les fichiers `facts-mini-*.csv` et `facts-mini.json` proviennent des exemples du TP2. Le programme charge les trois CSV ; le JSON est une référence de format, pas une entrée acceptée.

Résultats : 3 classes, 5 méthodes, 4 arcs représentant 5 sites ; 1 arc intra-classe écarté, 3 inter-classes ; couplages A–B=2/3, B–C=1/3, A–C=0. Le lien moyen fusionne à 2/3 puis 1/6 ; le lien simple à 2/3 puis 1/3. À CP=0.20 : un module accepté ; à CP=0.50 : deux modules rejetés car la limite entière vaut un.

`README-fourni.txt` conserve les explications et les valeurs calculées à la main par l'enseignant. Les démonstrations Java qu'il mentionne restent dans les fournitures originales locales et ne sont pas nécessaires pour construire ce projet.
